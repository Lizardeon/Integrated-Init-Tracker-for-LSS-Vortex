# Integrated Init Tracker for LSS Vortex

**Совместимость:** Tampermonkey / Violentmonkey / Violentmonkey / GreaseMonkey

**Платформа:** [LSS Vortex](https://vortex.longstoryshort.app/)

---

## 📖 Описание

**Integrated Init Tracker** — это пользовательский скрипт (UserScript), встраивающий полноценный боевой трекер инициативы прямо в интерфейс виртуального стола LSS Vortex. Инструмент спроектирован для мастеров (DM), позволяя полностью контролировать ход боя, здоровье монстров, статусы, тайминг ходов и логирование событий без необходимости переключения на внешние сервисы.

## ✨ Основные возможности

* **Полная интеграция с LSS Vortex:**
* Встраивается отдельной вкладкой **«Бой»** в стандартную панель вкладок.
* Читает данные игроков (имя, аватар, КД, текущие и временные хиты, системные статусы) из веб-интерфейса комнаты.
* Считывает броски инициативы из чата / логов комнаты LSS Vortex при создании нового столкновения.


* **Управление участниками и монстрами:**
* **Групповое добавление NPC:** Поддержка спавна нескольких одинаковых монстров за один раз (с автоматической нумерацией `#1`, `#2` и т.д.).
* **Умный ввод показателей:** Поддержка формул кубиков (например, `2d8+2` для хитов) и модификаторов (например, `+3` для автоброска инициативы `d20+3`).
* Гибкое редактирование параметров участника прямо в карточке (хиты, временные хиты, КД, инициатива, заметки).
* Быстрое удаление монстров или участников из боя по кнопке при наведении.


* **Автоматика и математика хитов:**
* Экспресс-ввод урона и лечения в карточке монстра (`-12`, `+5`).
* Автоматический урон сначала по временным хитам, затем по основным хитам.
* Управление временными хитами через префикс `t` (`t10`) и максимальными хитами через `m` (`m45`).


* **Учет времени и аналитика:**
* Автоматический таймер текущего хода и счетчик раундов.
* Подробная статистика: общее время боя, среднее время на раунд, индивидуальное время ходов каждого игрока (PC) и среднее время на ход.


* **Лог боя (Combat Log):**
* Автоматическое ведение журнала событий (переходы ходов, нанесённый урон, лечение, изменение статусов).


* **Управление интерфейсом и сохранность:**
* **Сворачиваемые секции и панель:** Возможность скрыть боковую панель управления целиком или сворачивать отдельные блоки (Управление, Добавить NPC, Аналитика).
* Автоматическое сохранение состояния боя в `localStorage` (бои не сбрасываются при перезагрузке страницы).
* Экспорт и импорт боя в формате `.json`.

## 🛠️ Установка

1. Установите браузерное расширение для пользовательских скриптов (например, **Tampermonkey**).
2. Перейдите по ссылке для установки:
* [Установить скрипт с GitHub](https://github.com/Lizardeon/Integrated-Init-Tracker-for-LSS-Vortex/raw/refs/heads/main/Integrated_Init_Tracker.user.js)

3. Подтвердите установку в появившемся окне Tampermonkey.
4. Откройте или обновите страницу своей комнаты в [LSS Vortex](https://vortex.longstoryshort.app/). На панели появится новая вкладка **«Бой»**.

## 🚀 Инструкция по использованию

### 1. Начало нового столкновения

1. Перейдите на вкладку **«Бой»**.
2. В боковой панели нажмите **«Новое столкновение»**.
3. В открывшемся окне выберите игроков, участвующих в бою. Скрипт автоматически найдет их броски инициативы из чата комнаты и затянет актуальные параметры Хиты/КД.

### 2. Добавление NPC / Монстров

В блоке **«Добавить NPC»** укажите:

* **Имя NPC** (например, `Гоблин`).
* **Количество** (например, `3` — создаст `Гоблин #1`, `Гоблин #2`, `Гоблин #3`).
* **Инициативу:** точное значение (например, `12`) или модификатор (например, `+2` для броска `1d20+2`).
* **Хиты:** точное значение (например, `15`) или формулу броска (например, `2d6+3`).
* **КД:** класс доспеха.
Нажмите **«Добавить в бой»**. Все участники автоматически отсортируются по значению инициативы.

### 3. Ведение боя

* Нажмите **«Начать бой»** для запуска таймера и отсчета раундов.
* Переключайте ходы кнопками **«След.»** и **«Пред.»**. При переходе хода автоматически уменьшаются счетчики временных статусов (например, `Заслеплен (2)` $\rightarrow$ `Заслеплен (1)` $\rightarrow$ удаление).
* **Применение урона / лечения к монстру:** в поле ввода хитов карточки введите:
* `-8` — нанести 8 урона (сначала вычитается из временных хитов).
* `+5` — вылечить 5 хитов (не превышая максимум).
* `t10` — установить 10 временных хитов.
* `m50` — изменить максимальный запас хитов на 50.

### 4. Статусы и заметки

* Для добавления статуса нажмите значок `+` на карточке участника, введите название (можно с длительностью, например: `Яд (3)`) и нажмите Enter.
* Нажмите на плашку статуса, чтобы удалить его вручную.

## ⚙️ Технические детали

* **Storage Key:** `vortex_IITStorage_v2` (localStorage).
* **Стили:** Динамическая инжекция CSS под дизайн-систему Mantine UI, используемую в LSS Vortex.
* **Адаптивность:** Поддерживается корректное отображение на мобильных устройствах и экранах с небольшим разрешением.
